============================================================
1. تعريف مشروع مدار
============================================================

اسم المشروع:
مدار | منصة الرياضيات التفاعلية

الشعار:
تعلّم • تدرّب • العب • أتقن

مدار هو مشروع منصة تعليمية تفاعلية متخصصة في الرياضيات.

الفكرة الأساسية ليست مجرد إنشاء موقع اختبارات، وإنما بناء نظام
تعليمي يساعد المعلمة على:

- إدارة الطالبات.
- إنشاء الاختبارات.
- إدارة بنك الأسئلة.
- ربط الأسئلة بالمهارات.
- متابعة نتائج الطالبات.
- تحليل أداء الطالبات.
- معرفة المهارات التي تتقنها الطالبة.
- معرفة المهارات التي تحتاج إلى تدريب.
- عرض الإحصائيات.
- استخدام النقاط التحفيزية.
- تطوير تجربة تعليمية تفاعلية.

المنصة موجهة أساسًا إلى:
- الطالبة.
- المعلمة.
- ولي الأمر.


============================================================
2. رؤية المشروع
============================================================

الهدف من مدار أن يتحول من منصة اختبارات إلى منصة تعليمية
متكاملة.

الطالبة
   ↓
تحل الاختبار
   ↓

   ↓

   ↓

============================================================
17. مشكلة PHP الأولى
============================================================

عند كتابة:

php

في Terminal ظهر:

php: command not found

السبب:
نسخة PHP التي نستخدمها كانت داخل MAMP وليست مرتبطة مباشرة
بـPATH الخاص بالنظام.

تم العثور على PHP داخل:

/Applications/MAMP/bin/php/php8.4.17/bin/php

وكانت النسخة:

PHP 8.4.17

============================================================

/Applications/MAMP/bin/php/php8.4.17/bin/php

ومن خلاله أصبح بالإمكان تشغيل PHP.


============================================================
19. تشغيل سيرفر PHP
============================================================

تم استخدام الأمر:

/Applications/MAMP/bin/php/php8.4.17/bin/php -S localhost:8000 router.php

تشغيل PHP Development Server
على localhost
على المنفذ 8000
واستخدام router.php لمعالجة الطلبات.
