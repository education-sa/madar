تحديث بنك الأسئلة الذكي
التاريخ: 19-07-2026

1) تصميم الأسئلة داخل الصفحة
- أُلغي فتح النوافذ المنبثقة عند اختيار طريقة التصميم.
- أصبح زر «اختاري طريقة تصميم الأسئلة» يفتح المحتوى أسفله داخل الصفحة نفسها.
- تظهر الأنواع الستة داخل المحتوى: توليد سريع، تشخيصي، فتري، احترافي، تفاعلي، ذكاء اصطناعي.
- يحفظ النظام آخر طريقة تصميم وحالة فتح القسم في الجلسة الحالية.

2) التصميم بالمهارات
- تُعرض مهارات المرحلة والصف المختارين تلقائيًا.
- يمكن اختيار مهارة واحدة أو عدة مهارات، أو كتابة مهارات إضافية يدويًا.
- يمكن تحديد عدد الأسئلة لكل مهارة، الصعوبة، وأنواع الأسئلة.
- تُربط الأسئلة الناتجة بالمهارات وتحفظ في المستودع بانتظار المراجعة.
- وضع «احترافي» أصبح نموذجًا يدويًا كاملًا داخل الصفحة دون نافذة منبثقة.

3) إصلاح استيراد Excel
- تطوير قارئ XLSX للتعامل مع ملفات Excel وGoogle Sheets وNumbers بصورة أفضل.
- دعم الأوراق الكبيرة، النصوص المشتركة، النصوص المضمنة، واختلاف اسم أو مسار ورقة العمل.
- إصلاح بعض أحرف XML غير الصالحة بدل إيقاف الاستيراد مباشرة.
- البحث عن صف عناوين الأعمدة حتى لو سبقه عنوان أو أسطر تمهيدية.
- دعم أعمدة «المهارة» و«رمز المهارة» وربطها بجدول المهارات.
- دعم الإجابة الصحيحة برقم الخيار أو حرفه: 1-4 أو أ-د أو A-D.
- دعم عناوين بديلة مثل «صيغة السؤال» و«الإجابة النموذجية».

4) نموذج Excel والتصدير
- إضافة زر «تحميل نموذج Excel» داخل نافذة الاستيراد.
- إضافة عمود «المهارة» إلى ملف التصدير.
- يمكن تصدير نموذج فارغ مطابق للاستيراد.
