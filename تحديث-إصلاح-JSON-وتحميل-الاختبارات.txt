تم إصلاح خطأ Unexpected token < في صفحة الاختبارات:
- منع PHP من طباعة التحذيرات بصيغة HTML داخل استجابة API.
- تنظيف مخزن الإخراج قبل إرسال JSON.
- تحويل الأخطاء القاتلة إلى JSON واضح.
- جعل قائمة الاختبارات متوافقة مع قواعد البيانات القديمة والأعمدة غير المرحلة.
- عدم تعطيل قائمة الاختبارات إذا فشل تحديث مخطط قاعدة البيانات.
- إضافة محلل احتياطي في JavaScript لقراءة JSON حتى عند وجود تحذير قديم قبله.
