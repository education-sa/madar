# تقرير تحقق حزمة مدار وبوابة ظليم

## فحوصات منفذة لهذه النسخة

- مطابقة ملفات `api/`, `lib/`, `owner/`, `student/` و`teacher/` المرفقة مع نسخة `education-sa/madar` على الفرع `main`؛ الملفات متطابقة.
- فحص صياغة JavaScript لوحدة البوابة وواجهة الطالبة بأداة Node.
- تشغيل اختبارات الاستبيانات والقوالب الحالية.
- مراجعة صلاحيات الخادم: مالكة مدار وحدها تدير دور معلم أول؛ معلم أول يدير المدرسة؛ المعلمة تحتاج اعتمادًا صريحًا ومادة مطابقة لكل ملف؛ الطالبة تُثبت عبر معرف حساب مدار النشط.
- مراجعة الترحيلات: تستخدم `CREATE TABLE IF NOT EXISTS` وتضيف جداول جديدة فقط، ولا تتضمن `DROP`, أو حذف/تعديل جداول الحسابات والاستبيانات.
- فحص محتويات الأرشيف قبل التجهيز لاستبعاد `config.php` وسجلات الأخطاء وملفات البيئة والبيانات الفعلية.

## لم يمكن تشغيله في بيئة البناء

لا يتوفر PHP أو MySQL في بيئة التنفيذ الحالية؛ لذلك لم يُنفذ PHP lint أو ترحيل MySQL أو اختبارات تكامل/تسجيل دخول. يلزم تنفيذ أوامر PHP واختبارات الصلاحيات على نسخة اختبار قبل النشر. لم يتم الاتصال بخادم الاستضافة أو تعديل قاعدة البيانات الحية.

## أوامر الاستكمال على نسخة الاختبار

```sh
cd surveys
php bin/check.php
php tests/domain.php
php bin/install.php
node tests/logic.cjs
node tests/personal_templates.cjs
node --check public/assets/board.js
node --check public/assets/board-student.js
```

بعدها اختبري مع بيانات تجريبية أن حساب الطالبة يُعاد توجيهه حسب وضع الوصول، وأن محاولات معلمة أخرى للوصول إلى ملف مادة مختلفة تُرفض، وأن سحب الصلاحية يمنع الاطلاع والتنزيل فورًا.
