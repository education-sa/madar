# مدار — منصة الرياضيات التفاعلية

نسخة محمولة مبنية بـ **PHP 8.1+** و **MySQL/MariaDB**. لا تعتمد على Replit أو خدماته، ويمكن حفظ الكود في GitHub وتشغيله على أي استضافة تدعم PHP وقاعدة MySQL.

> GitHub Pages يعرض ملفات HTML/CSS/JS فقط ولا يشغّل PHP أو MySQL. بعد إضافة الحسابات والاختبارات يجب نشر المشروع كاملًا على استضافة PHP، مع إبقاء المستودع في GitHub للنسخ الاحتياطي والتطوير.

## ما الذي تعمل عليه المنصة؟

- حساب مالكة الموقع مع إدارة المعلمات والطالبات والموافقة على حسابات المعلمات.
- حساب المعلمة: المعلومات وكلمة المرور، الفصول، الطالبات، ملفات الإنجاز، سجل المتابعة، الحضور، الواجبات والملاحظات.
- بنك أسئلة يدوي أو مولّد بالذكاء الاصطناعي، مع مراجعة المعلمة قبل اعتماد أي سؤال مولّد.
- اختبارات تشخيصية قبلية وبعدية واختبارات قصيرة، مع النشر والمواعيد والوقت والمحاولات.
- حساب الطالبة: الاختبارات المتاحة، ملف إنجاز لرفع PDF والصور، نقاط مدار، النتائج وإتقان المهارات.
- مراجعة المعلمة للإجابات القصيرة عند الحاجة وتحديث الدرجة والتحليلات.
- استبانة أنماط تعلّم إرشادية: بصري، سمعي، قرائي/كتابي، حركي أو مختلط.
- تحليل لكل طالبة، والفصل، والمهارة، وأنماط التعلّم، مع تقارير CSV وصفحات جاهزة للطباعة أو الحفظ PDF.
- جلسات آمنة، تشفير كلمات المرور، حماية CSRF، تحديد محاولات الدخول، وفصل الصلاحيات بين الأدوار.

## المتطلبات

- PHP 8.1 أو أحدث.
- MySQL 8 أو MariaDB 10.5 أو أحدث.
- إضافات PHP: `pdo_mysql`, `mbstring`, `json`, و`zip` لاستيراد Excel، و`fileinfo` للتحقق من ملفات الإنجاز، و`curl` عند استخدام الذكاء الاصطناعي.
- Apache مع `mod_rewrite`، أو Nginx باستخدام المثال داخل `deploy/`.

## تشغيل محلي سريع

1. أنشئي قاعدة بيانات فارغة باسم `madar`.
2. استوردي [database/schema.sql](database/schema.sql).
3. انسخي `.env.example` إلى `.env` وعدّلي بيانات قاعدة البيانات وكلمة مرور المالكة.
4. أنشئي أول حساب مالكة:

```bash
php scripts/create_owner.php
```

5. شغّلي الخادم المحلي:

```bash
php -S 127.0.0.1:8080 router.php
```

6. افتحي `http://127.0.0.1:8080`.

إذا كانت قاعدة البيانات منشأة من نسخة سابقة، استوردي مرة واحدة ملف `database/migration_20260716_teacher_tools.sql` لإضافة سجل المتابعة، ثم `database/migration_20260717_madar_points.sql` لإضافة تصنيفات وتفاصيل «نقاط مدار»، ثم `database/migration_20260717_student_portfolio.sql` لإضافة «ملف إنجازي». تحاول الواجهة تجهيز هذه التحديثات تلقائيًا أيضًا عند توفر صلاحية تعديل الجداول لمستخدم قاعدة البيانات.

يجب أن يكون المجلد `storage/private/student-portfolios` قابلًا للكتابة من PHP. تُحفظ الملفات داخله بأسماء عشوائية، ويُمنع فتحه مباشرة؛ عرض الملفات يتم فقط من خلال حساب الطالبة أو معلمتها.

بعد أول دخول احذفي قيمة `OWNER_INITIAL_PASSWORD` من `.env` وغيّري كلمة المرور إذا كانت قد ظهرت سابقًا في لقطة شاشة أو محادثة.

## بيانات تجريبية اختيارية

أضيفي في `.env` كلمتي مرور تجريبيتين ثم شغّلي:

```bash
php scripts/seed_demo.php
```

يُنشئ السكربت معلمة وفصلًا و12 طالبة وبنك أسئلة واختبارًا منشورًا. لا تشغّليه على الموقع الحقيقي إلا إذا كنتِ تريدين هذه البيانات فعلًا.

## الذكاء الاصطناعي

التوليد اختياري. أضيفي في `.env` عنوان واجهة متوافقة مع Chat Completions والمفتاح واسم النموذج:

```dotenv
AI_API_URL=
AI_API_KEY=
AI_MODEL=
```

المنصة لا تنشر السؤال المولّد مباشرة: تحفظه بحالة «بانتظار المراجعة»، تتحقق من بنيته، ثم تطلب اعتماد المعلمة. لا تضعي مفتاح الذكاء الاصطناعي داخل JavaScript أو GitHub.

## روابط الأدوار

- المالكة: `/owner/login.html`
- المعلمة: `/teacher/login.html`
- الطالبة: `/login.html?role=student`

## تحديث المنصة المتكامل v11

يتضمن الإصدار v11 البحث الشامل، الملف الموحد للطالبة، الخطط العلاجية، التنبيهات الذكية، تقويم المعلمة والطالبة وولي الأمر، الرسائل الخاصة مع ولي الأمر، لوحة إشراف للكادر الإداري، تحسين الجداول على الجوال، الخصوصية، حالة النظام، النسخ الاحتياطية والتقارير الذكية.

تبقى الأقسام المخطط لاستكمالها لاحقًا، مثل الأداء الوظيفي والمسابقات والاستراتيجيات، ظاهرة في الواجهة ولا يحذفها هذا التحديث.

