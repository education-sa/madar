## التحقق المنفذ
اختبارات تكامل فعلية باستخدام PHP 8.4.17 وMySQL 5.7 مع قاعدة تجريبية مستقلة، لا قاعدة الموقع:
1. تسجيل الدخول الأصلي والحساب الموحد للمعلمة والطالبة وولي الأمر.
2. أنواع الوصول الثلاثة لكل نوع حساب، ومنع استدعاء API مدار للحساب المخصص للبوابة.
3. منح وسحب دور معلم أول، فورية السحب، وبقاء دور مدار كما هو.
4. منع المعلمة المخولة والطالبة وولي الأمر من صلاحيات إدارة المعلمات.
5. اعتماد معلمتين لمادتي الرياضيات والعلوم في الفصل نفسه.
6. تكرار ربط الطالبة لا ينتج صفًا مكررًا؛ الفصل نفسه لا يتكرر بعنوان مختلف.
7. القائمة والتنزيل والحذف لا تكشف ملفات المادة الأخرى.
8. رفع ملف PDF فعلي من الطالبة وظهوره فورًا في المادة الصحيحة، ورفض المادة غير المعتمدة.
9. حفظ سجلات السحب والتغيير وفرض التأكيد من الخادم.
10. مقارنة بصمة بيانات الحسابات وكلمات المرور والفصول الأصلية واستبيان وقالب وإجابة تجريبية قبل الاختبارات وبعدها.
11. فحص PHP وJavaScript للملفات المعدلة، وفحص واجهة الأزرار في لوحة المالكة المحلية.
